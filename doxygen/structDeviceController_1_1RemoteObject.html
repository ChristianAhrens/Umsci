Detailed Description

A fully-qualified DS100 remote parameter: type, address, value.

Uses the same RemObjIdent enum as NanoOcp1::SoundscapeController::RemoteObject (values are identical) and a DeviceController::RemObjAddr (adds JUCE helpers).
